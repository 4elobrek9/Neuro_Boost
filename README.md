# Neuro Boost — WOW Edition (Flet)

Мощное приложение-тренажёр краткосрочной памяти с ярким UI, анимациями, ограниченными попытками, очками, монетами и магазином.

## Технологический стек
- **Python 3.11+**
- **Flet** (современный кроссплатформенный UI)
- **SQLite** (прогресс и экономика)
- Модульная архитектура (`core`, `games`)
- Roadmap мультистека: C/C++ движок мини-игр, Java/Kotlin онлайн backend

## Игры (MVP+)
- 🎴 Memory X (ограниченные попытки)
- 🔢 Digit Span (ограниченные попытки, прямой/обратный порядок)
- 🔲 Schulte Blitz (жизни + тайминг)

## Экономика и прогресс
- Очки + монеты за игры
- Магазин апгрейдов
- Сердца (лимит ошибок / энергосистема)

## Запуск
```bash
pip install -r requirements.txt
python main.py
```
